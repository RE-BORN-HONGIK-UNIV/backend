# 하루 대화 설계 노트

`haru/talk.py`는 1·2단계 대화 상대 하루가 방금 대답에 한 문장으로 반응하고 다음 질문으로 잇는 말과, 2단계가 끝난 뒤 "하루가 이렇게 이해했어요" 카드에 보여 줄 요약을 만든다. 질문 순서는 화면(frontend `features/haru/script.ts`)이 정하고, AI는 반응 문장만 만든다.

## 경량 웹에서 옮기며 바꾼 점

경량 웹(판넬 OVERVIEW용, reborn-lite)의 `/reply`를 팀 백엔드 규칙에 맞게 옮겼다. 원본과 다른 점은 다음과 같다.

- anthropic==0.69.0으로 고정된 환경이라 effort는 `llm_util.effort_options()`로 넘긴다(원본은 2.x 전용 `output_config`·`fallbacks`). JSON 형식은 프롬프트로 요청한 뒤 직접 파싱·검증한다.
- 위기 신호가 있는 대답은 AI로 보내지 않는다(`coach/safety.py`와 같은 기준).
- AI 출력은 길이·금지어(평가·진단 표현)를 검사하고, 통과하지 못하면 정해 둔 문장으로 대체한다.
- 실패해도 502가 아니라 항상 완성된 응답(`source='fallback'`)을 준다. 화면 흐름이 끊기지 않게 하려는 것이다.
- 로그에는 예외 종류만 남긴다(대답 내용은 민감정보).

## 부를 이름 뽑기

AI 없이 카드를 만들 때는 대답 앞부분을 그대로 쓰고, 사용자가 카드에서 고친다. 다만 부를 이름은 이름만 뽑는다. 예전에는 "지렁이라고 불러 줘"가 통째로 들어가서, 3단계 면접관이 그 문장 그대로 사용자를 부르는 문제가 있었다.

- "지렁이라고 불러 줘" / "세연이라고 해 주세요" / "제 이름은 지우예요" / "지우요" → 이름만 뽑는다.
- "○○이라고"는 이름+이(세연이)인지 이름 자체(지렁이)인지 글자로는 가를 수 없어서, '라고' 앞을 통째로 쓴다. "세연이"도 부르는 이름으로 자연스럽다.
